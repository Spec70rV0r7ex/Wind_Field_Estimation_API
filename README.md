# SAR Ocean Wind Retrieval API

This project extracts high-resolution ocean surface wind speeds using Sentinel-1 Synthetic Aperture Radar (SAR) and the CMOD5.N Geophysical Model Function. Background wind directions are derived from ERA5 reanalysis data to enable the inversion.
